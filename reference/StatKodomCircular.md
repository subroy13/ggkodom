# Stat for geom_kodom_circular

Assigns lane positions, maps each lane to an angular position and the
time variable to a radial position, then converts to Cartesian
coordinates for rendering in ordinary Cartesian space (no
`coord_polar`). Called automatically by
[`geom_kodom_circular()`](geom_kodom_circular.md); rarely needed
directly.

## Usage

``` r
StatKodomCircular
```

## Format

A ggproto object.
