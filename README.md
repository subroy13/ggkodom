# WashU I2DB Datathon

## Overview

This dataset presents a comprehensive, longitudinal view of patient health trajectories, integrating static demographic and socioeconomic factors (such as the Area Deprivation Index) with dynamic, time-varying clinical measurements and cumulative healthcare utilization metrics. Designed to facilitate predictive modeling in a clinical context, the primary objective is to forecast future glycemic control by capturing the complex temporal patterns in a patient's medical history. Specifically, the **`a1c_2025`** variable serves as the target label response, requiring models to classify or predict whether a patient's HbA1c levels will be uncontrolled in the year 2025 based on their historical comorbidities, medication regimes, and previous lab results.

Reference: https://i2db.wustl.edu/i2db-datathon-call-for-participation/

### Repository Structure

Following is the folder structures we will follow for repository management.

- Use `./data/` folder to store all the raw and processed datasets.
  - `./data/raw/` contains the raw train and test files provided by the I2DB team, and should not be modified, treat these as **READ ONLY** files.
  - `./data/processed` contains the processed / cleaned data files, including the train, test, validation splits etc.
    - Use `train.Rds` and `val.Rds` to train and validate your model.
    - Never use `test.Rds` until you have finalized your best model.

- Use `./figures/` to store any plots relevant to the EDA that you may find insightful.
- Use `./scripts` to write all your R scripts. A `.gitignore` file is already added to ensure temporary files generated by R process is not committed.

- `Readme.md` contains the basic overview of the entire project. 
- `changes.md` contains findings (or changes) list that we will maintain to describe the changes we made / insights we find. Basically it describes what we did, and why we did it.


### Raw Dataset Overview

There are two data files:

- `DM Features.csv` contains the feature variables to be used for training the model.
- `DM Control_2025.csv` contains the target response (binary) to be used to train the model.
